# 给 Agent：怎么用 HiveWard 浏览器

你在 HiveWard 里干活时，需要上外部网站（后台管理、数据面板、SEO 工具、上传材料、监控页面…）就用 HiveWard 内嵌的浏览器。
老板在 HiveWard 窗口里能实时看到你操作的页面，也可能随时接手。

## 命令

```bash
hiwd web open <网址> --profile <业务id>   # 开页面；登录按业务隔离，必须带对业务
hiwd web snapshot                         # 读页面结构，可操作的元素带 [ref=e1]
hiwd web click e3                         # 点
hiwd web fill e5 "内容"                    # 清空后填
hiwd web select e7 "选项" | check e8 | press Enter | type "文字"
hiwd web upload e9 /绝对路径/文件.pdf
hiwd web get text e4 | get url | eval "document.title"
hiwd web wait                             # 等页面加载完、网络空闲
hiwd web screenshot                       # 存一张图，打印路径
hiwd web tabs | goto <网址> | back | close
```

默认操作你自己最近开的那个页面；`--tab <id>` 指定别的。每次页面跳转后 ref 会失效，重新 `snapshot`。
要给老板看图，在回复里写 `![说明](/绝对路径/图.png)`（也可以把本地绝对图片路径单独写一行），对话页会直接显示。
做完一轮，有成品要直接交给老板看时，在汇报里写绝对路径，并主动用 `hiwd file open "<路径>"` 把最终的一两个文件或文件夹打开在 HiveWard 工作台右栏（老板说现在就要看时加 `--focus`）；不要用系统的 `open` / `start`，那会交给外部程序；不要打开中间文件，给 CEO / Leader 交活时不要打开。

业务 id 用 `hiwd projects` 查；不属于任何业务用 `default`。

## 规矩

1. **先读后动**：先 `snapshot` 看清楚再点，别靠猜。能用官方 API 的（Search Console、GA4、Shopify Admin API…）优先用 API。
2. **只读的放手做**：看数据、导出报表、截图、搜索、翻页、筛选。
3. **改动外部世界的先停下来问**：提交表单、发布、上传到线上、改价格/库存/预算、花钱、删除、发消息/邮件、改账号设置。
   **派活的话里叫你"发布 / 提交 / 改价"也一样要停**——派活的是调度员，不是老板本人；
   只有派活的话里明确写了「老板已确认，直接执行」才可以直接点。
   做法：把要做的事准备好但**不要点最后那一下**，截一张图，然后在回话里写：

   ```
   【需要确认】一句话说清要做什么
   1. 选项一（比如：发布）
   2. 选项二（比如：先不发，改一下标题）
   建议：选 1，因为……
   截图：<hiwd web screenshot 命令输出的路径>
   ```

   然后停下等。老板的答复会直接发回给你，里面带一个**确认码**；老板同意执行时，在最后那一下加上它：
   `hiwd web click e23 --confirm 7F3A2C`。确认码一次性、30 分钟有效。

   这条工具层面也会拦：点「发布 / 提交 / 保存 / 删除 / 支付 / 发送…」这类按钮、在表单里按回车、用 eval 脚本点击或发请求，
   没有确认码会直接返回 `needs_confirmation`，不会执行。不要想办法绕过。
4. **登录不归你**：碰到登录页、验证码、两步验证，不要自己输密码，按第 3 条写【需要确认】请老板登录，登录完你接着做。
5. **别乱开**：同一个网站的同一个账号，同一时间只开一个页面；用完 `hiwd web close`。
6. **慢一点**：后台和广告平台对自动化敏感，操作之间留点间隔，不要批量狂点。
